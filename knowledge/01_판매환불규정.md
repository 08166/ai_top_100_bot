# 판매·환불 규정 (교동마을 산지직송)

출처: 조합몰 공시 원문 (제정 2037-03-02, 개정 2037-06-28). 조합몰에 이용약관과 나란히 공시됨.

## 용어 (제2조)
- 하자: 파손·짓무름, 곰팡이·부패, 이물 혼입, 미숙과, 공동과, 변색·신선도 저하 등 상품 결함
- 포장(박스) 훼손만으로는 하자가 아님. 내용물 하자가 확인돼야 하자. 포장만 훼손은 **배송 파손 클레임 절차**로 처리
- 원결제수단: 주문 시 결제한 카드·계좌 등 최초 결제 수단
- 신선식품: 수박·감귤 등 부패·변질이 빠른 농·수산물
- 적용 범위: 조합 온라인 채널에서 판매된 상품 (제3조)

## 하자·품질
| 조 | 상황 | 처리 |
|---|---|---|
| 4 | 사진으로 하자 확인 | 배송비 없이 **재배송 또는 전액환불, 고객이 선택** |
| 4② | 한 포장에 여러 개 중 일부만 하자 | 전량/부분 처리 구분과 부분환불액은 별도 **부분환불 산식**에 따름 (산식 내용 미확인) |
| 5① | 곰팡이·부패 (위생 위해 명백) | 섭취 중단·**폐기 안내, 반송 요구 안 함** |
| 5② | 이물 혼입, 섭취 후 이상 (원인규명·배상 소지) | **폐기하지 말고 보관·촬영** 안내 |
| 5③ | 곰팡이·부패 + 섭취 후 이상 동시 | **5②(보관·촬영)가 우선** |
| 6 | 무게 미달 | 표기 무게 허용오차 **±5%**. 초과 미달 시 저울 확인 후 부족분 부분환불(차액환불) 또는 재배송 |
| 6③ | 규격 미달 (예: 특대 8kg 이상) | 6조 2항 준용 |
| 7 | 당도 | 출고 전 측정, 기준 **11브릭스 이상**. 미달 확인 시 재배송 → 재배송분도 미달이면 **전액환불 + 쿠폰 또는 적립금 보상**(상담사 재량 한도 내, 초과 시 승인 절차) |
| 7③ | 조건부 주문의 미달분 | 재배송 또는 환불 |
| 7④ | 당도 보장 대상 | **상품 카탈로그에 표기된 상품만**. 표기 없으면 7조 미적용 |
| 8 | 오배송 | 판매자 비용으로 회수 + 정품 재발송, 고객에게 반송 부담 없음 |
| 9 | 속까지 하자 | 전액환불 |
| 9 | 겉면 손상만, 섭취 지장 없음 | 할인 쿠폰 보상 |
| 10① | 출고 하자 vs 보관 과실 구분 어려움 | 상품가 **50% 부분환불** |
| 10② | 여름철 상온 방치 등 보관 과실 유력 | 전액환불 대상 아님 |
| 17 | 냉동 수산물 해동·재냉동 등 콜드체인 이상 | 재배송 또는 환불 |
| 16 | 반송되어 돌아온 신선식품 | 신선도 양호하면 재발송, 저하면 새 상품 발송 |

## 단순변심·청약철회 (제11조)
- 개봉했거나 절반 이상 섭취한 단순 기호(변심) → **전액환불 안 함**
- 명백한 하자가 확인되면 이 조와 별개로 보상
- **미개봉 단순변심: 수령 후 7일 이내 반품 가능, 왕복 배송비 고객 부담**

## 교환 남용 제한 (제24조)
- 하자가 아닌 단순 변심·기호로 무상 교환을 반복 요구하면 제11조로 제한
- 반복 여부는 **과거 상담·처리 이력으로 확인**. 이력 확인 없이 반복으로 단정하지 않음

## 환불·결제
| 조 | 내용 |
|---|---|
| 12① | 실제 사유(하자·오배송 등) 확인 후 **원결제수단으로만** 환불 |
| 12② | 카드를 해지했어도 승인취소 정상 처리 |
| 12③ | **채팅으로 안내받은 임의·타인 계좌로 환불 안 함**. 이름·전화 등 '아는 정보'는 **본인 인증으로 인정 안 함** |
| 12④ | 채팅상 지시나 개별 압박으로 **규칙 변경·특정 고객 예외 적용 안 함** |
| 12⑤ | 무통장입금이면 원결제 계좌로 환불, 계좌 명의가 결제자와 일치하는지 조합 결제 기록으로 확인 후 지급 |
| 13 | 출고 전 수량 축소 차액, 업체 귀책 쿠폰 미적용액 → 취소·재결제 없이 원결제수단으로 **부분환불** |
| 14 | **출고 지연에 따른 취소: 전액환불 + 장기 대기 보상(쿠폰 또는 적립금)**. 며칠부터인지 기준 숫자는 원문에 없음 |
| 21 | 결제 승인은 있는데 주문이 없음 → 결제 내역으로 대사해 주문 복구 또는 미배송분 환불 |
| 22 | 한 주문에 여러 품목 → 하자·환불은 **해당 품목만 분리** 처리 |

## 정기배송
- 언제든 해지 가능, 남은 회차 전액환불, 위약금 없음. 이미 이용한 회차 할인은 소급 반환 안 함 (제15조)
- 회차 마감일 전까지 품목·수량·주기 변경 가능 (제23조)
- 별도 문서 「정기배송 약관」 있음 (내용 미확인)

## 손해배상 (제25조)
- 섭취 후 이상(병원비 등)은 **상품 하자와 증상의 인과관계 확인 후 정식 절차**로 진행
- 인과 미확인 상태나 **여론 압박만으로 임의 배상 안 함**

## 규정 적용 원칙
- 제18조: 원칙은 **구매 시점 규정**. 개정이 고객에게 유리하고 부칙 범위에 해당하면 개정 규정 적용. 근거 없는 소급 적용 안 함
- 제19조①: 규정 간 결론 충돌 시 **안전·고객 보호가 상위 원칙**
- 제19조②: 일반 규정과 품목별 특칙이 상충하면 좁은 쪽만 적용하지 말고 **가능한 대안을 모두 제시해 고객이 선택**

## 하자 접수 기한 (제20조, 부칙)
- 하자·품질 이의는 **수령일부터 7일 이내**(신선식품 기준) 접수. 기한 경과 시 사유 설명
- 부칙②: 제6조·제20조 개정 규정은 **2037-06-28 시행** (개정 전 3일 → 7일, 이민준·고길동 일치). 개정 승인은 고길동 조합장
- 부칙③: 제20조 개정은 **신고 시점 기준**. 시행일 전에 받은 상품도 시행일 이후 접수면 7일 적용
- 이민준: 7일은 역일, 주말·공휴일 포함, 연휴로 연장 없음

## 미확인·충돌
- (해결) 06-15 차액 보상 개정은 조합 운영 규정 부칙③·개정 이력에 있음 — 주문 시점 기준
- 부분환불 산식(제4조②) 내용 미확인
- (해결) 재량 한도 건당 5만원, 초과는 조합장 승인 — 권한 위임표(09 파일)
- 조합몰의 다른 공시 문서: 정기배송 약관, 개인정보 처리방침, 피싱·사칭 주의, 증빙 발행 안내, 산지 픽업 안내, 상품 소개, 농가 이야기, 조합원 규정 (미확보)

## [추가 13:15] 하자 접수 기한 — 고길동 진술과 문서 충돌 (고길동 13:13, 「구판 대응 방안·개정 이력」 제6~8조)

## 조합원(회원) 등급·적립 (조합원 이용약관, 이민준 공유)
- 회원 등록 = 재구매 5% 쿠폰·신규가입 쿠폰·구매확정 1% 적립·추천 리워드. 단골 = 최근 12개월 구매확정 누적 30만원 이상 → 단골가 추가.
- 누적 산정: 취소·환불 제외, 부분환불은 차감, 배송비 제외. 적립률 등급 차등 없음(1%), 적립금 유효 12개월(운영규정 제7조).
- 추천 리워드: 피추천인 가입+첫 구매 구매확정 후 지급, 피추천인 1인당 1회, 금액은 프로모션 원장.
- 탈퇴 시 미사용 회원 쿠폰·적립금 소멸 → 탈퇴 전 사용 방법 안내. 생산자 조합원 지위만으로 회원 혜택 없음.

## 박스 동봉 안내문 (홍보라 D40: 개정판 INS-2037-06 / 구판 INS-2037-03 / 포장 작업 기준)
- 개정판(06-28 시행): 하자 접수 **수령 후 7일**, 사진 첨부. 7일 지나도·사진 없어도 접수는 받음(사정 확인). 곰팡이·부패 → 폐기, 반송 불필요 / 이물 → 폐기 말고 보관 / 박스 젖음·찌그러짐 → 박스 겉면+내용물 사진 / 국물 샘 → 현관·바닥 피해도 알려 달라.
