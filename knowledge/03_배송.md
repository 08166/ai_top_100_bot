# 배송

담당: 구방만 기사 (실제 집하·배송 현장 사실). 근거 문서: 택배 계약서.

## 확인된 것
- 산지직송이라 **당일배송 불가**, 보통 주문 다음 날~모레 도착 (이민준)
- 수취인 부재·주소 오입력으로 반송되면 **재배송비는 고객 부담이 원칙** (이민준)
- 배송 중 파손 책임은 택배 계약서로 따로 판단 (이민준)
- 포장(박스)만 훼손되고 내용물이 멀쩡하면 하자가 아니라 **배송 파손 클레임 절차** (규정 제2조)
- 반송되어 돌아온 신선식품: 신선도 양호하면 재발송, 저하면 새 상품 발송 (규정 제16조)

## 택배 계약서 조항 목록 (내용 미확인)
배송 단계, 집하 경계, 배송 소요, 대량 주문 배차, 합배송 제한, 분할 배송, 배송 위치 메모, 재배송비 부담, 배송 중 파손, 배송 사고·분실 책임

## 미확인
- 집하 마감 시각, 지역별 소요, 도서산간, 재배송비 금액
- 출고 지연 취소가 가능해지는 지연 일수 (규정 제14조에 숫자 없음)

## [추가 2026-10-31] 택배사 계약서·결항 기록 (근거: 이민준·구방만 제공 「택배 운송 위탁 계약서」(시원배송), 「시원배송 결항·집하 기록」, 인터뷰)
- 배송 단계: 물품 준비 → 송장 등록 → 집하(출고) → 배송 중 → 배송 완료 → 구매 확정. **집하 전**엔 배송지 변경·취소 가능, **집하 후** 변경 불가(수취 거부 시 자동 반송). 집하 시각 = 시원배송 집하 스캔 기록.
- 송장 등록 후 조회 반영까지 통상 **3~5시간** — 그 사이 조회 안 되는 건 정상(지연·사고 아님). **송장 존재 ≠ 배송 개시**.
- 산지직송은 당일배송 불가, 통상 **익일~모레** 도착. 기상특보·결항·도로 통제로 지연 가능.
- 대량 주문: 분할 배차 가능, 지정일 납기 위험 시 우선배송·대체 배송. 분할 확정 시 잔여 회차 예상 도착 사전 고지.
- 합배송 제한: 상온(농산)과 냉장·냉동(수산)은 같이 못 보냄 → 별도 포장·배송비 발생 가능. 같은 수령지 출고 전 복수 주문은 합포장 가능(절감 배송비 환불/정산).
- 분할(부분) 배송(고객 요청): 회차별 배송비 발생 가능, 최초 출고일부터 **7일 이내, 최대 3회차**. 초과는 별건 주문.
- 배송 위치 메모(문 앞·경비실·무인함) 가능, 분실·훼손 위험 사전 고지.
- 재배송비: 고객 귀책(부재·주소 오입력) 반송은 고객 부담 원칙, 사안에 따라 일부(절반 등) 분담 가능 — 상담 재량 한도 내, 사유 기록. 반송 재배송은 배송지 변경 요청으로 받음.
- 배송 중 파손: 시원배송에 파손 클레임 접수하되 **고객 재배송·환불을 먼저**, 조합-택배사 분담은 나중에 정산. 택배사 책임 구간이라는 이유로 고객 구제 지연·전가 금지.
- 분실(배송완료인데 미수령): 택배사 조사 접수, 고객 과실 아니면 조합이 **우선 재발송**.
- 출고지 배정: 교동 출하장 = 교동 배정 기사(구방만, TR-KD-01, 농산 10품목 + 전 품목 집하 등록·간선 인계) / 갯마을 출하장 = 갯마을 배정 기사(박민아, 냉동 탑차 TR-GM-02, 수산 2종). 갯마을 냉동분은 교동 출하장 경유 → 집하 등록 → 간선. 배정 기사 개인 연락처는 통지 대상 아님.
- 정기 출고일 월·수·금(+성수기 추가). 토·일·공휴일 출고 로트 없음.
- 6월 결항 이력: 06-02 태풍 예보(—, 미확정) / 06-04 예비특보·간선 지연 가능성 통보 / 06-05 강풍·풍랑경보 → 선박·항공 결항, 간선 중단, 집하 인수 보류(애플망고·수박·감자) — 애플망고는 06-04 수확·포장, 06-05 09:10 송장 등록, 11:40 집하 취소 / 06-06 결항 지속, 포장분 산지 냉장 대기(택배 인수 전) / 06-07 15:00 간선 재개(일요일이라 집하는 06-08 월 09:00부터, 밀린 물량 순차) / 06-18·06-25~29 배송 정상 / 06-30 특보 없음·정상.
- 작황·물류 지연은 별개 사유. 수확·포장 완료 후 결항으로 인수 안 되면 사유·예상 재개 시점 안내 후 ⑴재개 후 출고 ⑵전액환불 중 고객 선택. 신선도 저하 예상 시 기존 포장분 대신 재수확분(산지 캘린더 제1조의2).

## 응답시간·비동기 SLA (이민준 공유, 시스템 운영 문서)
- SLA-01 30초 = 첫 응답 마감(봇) / SLA-02 45초 = 외부 조회(배송 조회 등) p95 / SLA-03 90초 = 비동기 대기 상한.
- 조회 1회 실행 → 30초 내 중간 안내 → 같은 조회 유지(재호출·취소 X) → 결과 오면 같은 상담에서 이어 답변. 같은 대상 재조회 60초 간격(LIM-08).
- 중간 안내 문안: "택배사 배송 조회를 접수하였습니다. 현재 결과를 기다리고 있으며, 확인되는 대로 이어서 안내드리겠습니다. 다시 문의하실 필요 없이 이 대화로 알려드리겠습니다." — "곧 나옵니다/1분 안에" 금지.
- 90초 초과: 대기 종료, 알림 구독 전환(LIM-09). "택배사 조회가 지연되어 아직 결과가 확인되지 않았습니다. 기존 조회를 유지하고 결과가 확인되는 즉시 먼저 안내드리겠습니다. 지금 당장 확인이 필요하시면 담당자에게 바로 넘기겠습니다."

## 영업일·공휴일 달력 (이민준 관리, 원문 reference/_text/이민준__영업일공휴일달력_*.txt)
- 영업일 = 월~금(토·일·공휴일·대체공휴일 휴무). 집하·출고는 영업일만. 산지 출고 월·수·금, 출고일이 휴일이면 그 회차는 건너뜀(다음 영업일로 미루지 않음). 하루 경계 24:00. 휴무일 접수는 다음 영업일 기산.
- 역일 기한(연휴에도 흐름): 하자 접수 7일(수령일), 청약철회 7일(수령일), 가격 인하 차액 7일(구매일), 적립금 소멸 예고 30일. 영업일 기한: 정기배송 컷오프 결제일 3영업일 전 24:00(당일 불산입), 이관 회신 3영업일. 송장 등록→조회 반영 3~5시간.
- 영업일 계산: 당일 불산입, 다음 영업일이 1일차, N일차 24:00 기한. 예: 07-24(금) 접수 → 07-29(수) 24:00 / 08-14(금) → 08-20(목) / 09-22(화) → 09-30(수).
- 컷오프 예: 결제 07-29 → 07-24(금) 24:00 / 08-19 → 08-13(목) / 09-30 → 09-22(화) / 10-07 → 10-01(목) / 12-28 → 12-22(화). 금 24:00 이후(토·일) 접수는 월요일 기산 → 회차 판정 갈림.
- 2037 공휴일: 05-06(수), 05-25(월), 06-06(토, 대체 없음), 08-15(토)→08-17(월) 대체, 09-23~25 연휴, 10-03(토)→10-05(월) 대체, 10-09(금), 12-25(금).
- 월별 출고 회차: 3월 13, 4월 13, 5월 11(최저), 6월 13, 7월 14(수박 성수기 최다), 8월 12, 9월 11, 10월 11, 11월 13, 12월 12.
- 연휴 중 배송 지연은 판매자 귀책 아님. 택배사 휴무는 택배사 계약서 별도. 임시공휴일 지정 시 회차 감소.
