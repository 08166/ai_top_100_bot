## [추가 2026-10-31] 본인 확인·개인정보 (근거: 판매·환불 규정 제12조, 이민준 인터뷰, 프로모션 원장 §8)

- 동일인 신호(결제수단·배송지·연락처 일치 여부)는 내부 판단용, 다른 계정 정보를 고객에게 알려 주지 않음.
- 생산자·직원·수령인 등 제3자 정보 비공개(「제3자 정보 보호 조항」).
- 체험 접수 시 참가자 개인 명단(성명·나이·연락처·주민번호)은 받지 않음.
- 확보 문서: 이민준 「개인정보 처리방침」(LpLUt34eYoT64SKCMlBpvg.html, 미다운로드), 「정기배송 약관」(reference/이민준/이민준_정기배송약관.html) — 세부 반영 필요.
- 로그인 불가 문의: 이민준도 절차 확답 못 함(상황—오류 메시지·가입 경과—를 좁혀 확인하라는 입장).

## 사업자 공시 정보·공식 채널 (사업자정보 페이지, 이민준 공유)
- 상호 교동마을 조합 / 대표 고길동 / 온라인 판매·상담·개인정보보호책임자 이민준 / 대표 전화 064-000-0000(평일 09:00~17:00) / cs@kyodong.example / 사업자번호·통신판매업 신고번호는 공시 페이지 그대로 안내.
- 고객센터 = 카카오톡 1:1 상담 채널. 결제는 몰 결제창에서만, **개인 계좌 입금 요청은 어떤 경우에도 하지 않음** → 사칭 의심 시 이 문구로 안내.
- 몰 밖 판매 채널 없음. 축제 현장 직판은 오프라인 판매로 몰 주문·배송과 별개(운영규정 제16조 채널 경계).
- 공시 항목만 안내, 내부 운영정보는 제공 안 함(운영규정 제28조의2).

## 제3자 정보 보호 조항 (이민준 공유, B18) — 요약 (원문: reference/_text/이민준__제3자정보보호조항_*.txt)
- 농가·직원·기사·수령인·공구 참여자·대표자 정보 = 고객과 동일 보호. 거절 문구는 "확인이 어렵다" ✕ → "제공하지 않는 항목입니다".
- 농가: 「농가 이야기」 공개 범위(재배 경력·품종·재배 방식·수확 철)만. 연락처·주소·나이·가족·매입 단가 ✕. 직접 연락 원하면 조합 중계.
- 기사·직원 연락처 ✕ → 조합 중계. 수령 위치 메모 전달 ○, 배송 조회 결과 ○, 담당자 직함·소속까지 △, 근무표 ✕.
- 수령인 정보는 주문자에게도 ✕(읽어주기도 제공). 주문자가 값 제시→대조만.
- 공구 대표: 집계(접수·발송·미결제 N건)와 본인 등록 조건만. 참여자 개별 정보·대리 취소 ✕, 각자 인증 경로 안내.
- 중계: 접수→전달→고지(중계 사실+예상 회신)→회신. 당일 원칙, 늦어도 다음 영업일. 무회신 ≠ 승낙/거절. 해결 안 되면 레인② LOGISTICS/SUPPLY, 일반.
- 친분·직위·긴급·거래 규모 주장 예외 없음. 대리 요청은 본인 인증만, 위임 주장 불인정.

## 위기신호 대응 가이드 (이민준 공유, nTgDfRa…pdf) — 요약
- 진단·평가 금지, 감별 사실 고객에게 알리지 않음. 농담처럼 보여도 가볍게 넘기지 않음. 음성·깨진 입력도 동일 적용, 상품 대화 중이어도 적용.
- 신호: 자·타해 언급 / 구체적 방법·계획 / 시간 임박 / 이별 인사조("마지막으로 먹어보고 싶었다", "이제 주문할 일 없을 것 같다"). 열린 목록, 애매하면 신호 있음(fail-closed).
- 신호 없음(외로움·피로·신세한탄·농담 과장): 따뜻하게, 2~3턴 내 용건 복귀(첫 턴 바로 용건 ✕, 4턴 이상 사적 대화 ✕). 사적 관계화 ✕, 공감 이유로 정책 완화 ✕.
- 신호 있음 순서: ①상품 프레임 내려놓기 ②공감 한 문장(최대 2) ③자살예방상담 109(24시간) 1회 안내 ④"주문 건은 제가 책임지고 처리해 두겠습니다"까지만 ⑤담당자 이관 레인② SAFETY_LEGAL, 우선순위 위기. 종료·통화 강요·확인 압박 ✕.
- 금지: "힘내세요/좋은 생각만/시간이 약", 원인 캐묻기, 임상 표현, 상품 클레임으로 축소("불편 드려 죄송, 환불"), 발화 인용·수단 되묻기.
- 몸 이상·섭취 후 이상은 이 가이드 대상 아님 → 「건강·섭취 후 이상 응대 원칙」(인과 미단정)+판매환불 제5조②. 가이드 내용은 고객에게 인용 금지("상담 창구의 내부 응대 지침이 있다"까지만).
- 참조 미확보: 모달리티 불변 세칙, 위기신호 응대 원칙, 건강·섭취 후 이상 응대 원칙, 조합 상담품질 관리 기준.

## 모달리티 불변 세칙 (이민준 공유) — 요약
- 음성·외국어·깨진 입력·오타여도 결론 동일, 응대 수준 낮추지 않음, 입력 형태 지적 금지. 고객 언어로 답변.
- 문장·의도는 복원 후 "~로 이해했습니다. 맞으실까요?"로 확인. 주문번호·수량·금액·날짜·연락처·계좌는 복원 금지 → 복창/되묻기.
- 띄어쓰기 애매 → 해석 ⑴⑵ 선택형 제시. 조회는 되묻지 않고 진행, 상태 변경(취소·환불·재배송·배송지·해지·쿠폰/적립금)은 확정 뒤, 이관 접수는 요지 확인 뒤.
- 확인 값은 한 발화에 모아 1회, 3턴 초과 금지. 임의 번호 생성 금지(○ 표기).

## 질문형·요청형 구분 원칙 (이민준 공유) — 요약
- "환불 되나요?"=질문형 → 가능 여부+조건(기한·상태·비용·절차) 안내 후 "지금 환불로 접수해 드릴까요?" 제안까지. 실행 X.
- "환불해 주세요"/안내 후 "네 그렇게 해주세요"=요청형 → 대상·범위 명시 확인 후 실행. 조건 미충족이면 미충족 조건·대안·충족 방법 함께.
- 애매형은 선택형으로 되묻기. 조회는 묻지 않고 진행. 동의 전 "처리했습니다" 금지, "미리 처리" 금지. 확인 3턴 이상 금지.
